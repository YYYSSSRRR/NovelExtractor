# 泛化抽取：对比与消融实验

> **读这张表之前先看三条限定**（README 6.3 有同样的说明）：
>
> 1. **它不由本仓库的产物复算得出。** 样本是现场抓的 359 个唯一 URL，与交付语料
>    `data/pages.jsonl` 只有 3 个 URL 重合（host 层面 30/99）。要复核必须重跑
>    `./bin/eval`，而网页内容会变，重跑的数字不会与下表逐格相同。这张表的用途是
>    **同一批页面上各配置之间的相对比较**，不是绝对水平。这个 3 是对
>    `sample_urls.tsv` 与语料的 `final_url` 求交集得到的（`www.0577hr.com` 那条
>    http→https，按 `url` 字段匹会少一个，得 2）。
> 2. **最后一行跑不出来。** `novel-extractor` 二进制不在本仓库（见 README 5.1）。
>    用 `-baseline ""` 重跑会跳过它，其余行照常。
> 3. **「正文率」这一列被单页绑架。** 它的口径是 `Σ抽出字符 ÷ Σ整页可见字符`，
>    不是 367 个单页比值的平均。样本里 `changba.com/redirect/latest_app.php` 一页的
>    可见文本就有 2,977,398 字符，占全部 367 页可见文本的 **72.2%**——这个比例可以
>    直接从 `sample_urls.tsv` 的第二列加总算出来。所以这一列主要在量那一页，
>    **不要当"平均覆盖率"读**，只在行间比较时有效。

样本：现场抓取的真实网页 **367 行 / 99 个 hostname**（唯一 URL 359 条，有 8 行重复），
按种子表等距取样，选页只依据 URL 形态与整页可见文本长度，不经任何被测实现的判据。

| 配置 | 空结果率 | 正文率 † | 标点密度 | 跨页模板残留率 | 标题非空率 | 平均正文长度 | 单行输出占比 |
|---|---|---|---|---|---|---|---|
| 完整版（本实现） | 15.0% | 10.6% | 0.093 | 0.01% | 98.6% | 1195 | 0.0% |
| 消融：关标点率 | 15.8% | 10.8% | 0.092 | 0.01% | 98.6% | 1216 | 0.0% |
| 消融：关链接惩罚 | 25.1% | 10.4% | 0.093 | 0.01% | 98.6% | 1174 | 0.0% |
| 消融：关祖先累积 | 12.0% | 5.6% | 0.100 | 0.00% | 98.6% | 632 | 9.5% |
| 消融：关跨页标题学习 | 15.0% | 10.6% | 0.093 | 0.01% | 98.6% | 1195 | 0.0% |
| 消融：关跨页模板过滤 | 15.0% | 11.3% | 0.092 | 6.03% | 98.6% | 1265 | 0.0% |
| 单页模式（两个跨页机制全关） | 15.0% | 11.3% | 0.092 | 6.03% | 98.6% | 1265 | 0.0% |

† 见上文限定 3。‡ 见上文限定 2。

指标口径：

- **空结果率**：`main_content` 为空的比例。越低越好，但空不一定错——栏目页、列表页本就无正文可抽。
- **正文率**：抽出文本的非空白字符数 ÷ 整页可见文本的非空白字符数。太低是漏抽，太高是把导航模板也抽了进来。
  **超过 100%（表里那 198.8%）说明抽出来的东西比整页可见文本还多**，那只能是重复或混入了隐藏
  内容——它是对照实现的问题，不是"抽得更全"。
- **标点密度**：抽出文本里标点字符的占比。正文是成句的，导航不是；这个值明显偏低说明抽进来的东西不成句。
- **跨页模板残留率**：把同一域名的输出当成新语料再学一次模板，还能剥掉的字符占比。没人标注也能算，且对所有实现是同一把尺子。
- **单行输出占比**：正文超过 200 字却一个换行都没有的比例。段落结构丢了，语料的分段信息也就没了。

`sample_urls.tsv` 的两列分别是 URL 与**整页可见文本的非空白字符数**，
上面那 72.2% 就是拿第二列算的。

## 复现命令

```bash
go build -o bin/eval ./cmd/eval
./bin/eval -domains 150 -per-host 4 -out eval -baseline ""
```

第二条里的 `-baseline ""` 用来跳过不在本仓库的对照组。不传则用默认路径
`../novel-extractor/novel-extractor`；找不到时程序打印一行提示然后继续，不会报错退出。
