# web-extract

> 通用网页正文抽取引擎 + 礼貌并发爬虫（Go 语言实现）。
>
> **核心原则**：不读 class/id、不设关键词表、零特定站点适配，基于统计物理特征与 DOM 树形动态规划，跨站点高精度抽取正文与真实标题。

## 一、 系统架构与模块构成

系统由四个高度解耦的子系统构成，支持独立运行与流水线级联：

```
┌────────────────────────────────────────────────────────┐
                │ 1. 种子发生器 (cmd/seeds)                              │
                │    名单聚合 ──▶ eTLD+1 归一 ──▶ 汉字探活 ──▶ seeds.txt │
                └───────────────────────────┬────────────────────────────┘
                                            │
                                            ▼
┌────────────────────────────────────────────────────────────────────────────────────────┐
│ 2. 礼貌并发爬虫 (cmd/crawler)                                                          │
│    Frontier 调度器 (Per-Host队列 + 最小堆) ──▶ Task(背压) ──▶ Worker 池 (N=32)         │
│          ▲                                                        │                    │
│          └─────────────── Done (冷却重入堆) ◀──────────────────────┴──▶ Gate (物理出口) │
└───────────────────────────────────────────────────────────────────────────┬────────────┘
                                                                            │
                                     ┌──────────────────────────────────────┴────────────────────────────────────┐
                                     ▼                                                                           ▼
┌────────────────────────────────────────────────────────┐ ┌─────────────────────────────────────────────────────┐
│ 3. 通用抽取引擎 (cmd/extractor & internal/extract)     │ │ 4. 容灾存储与评测 (internal/store & cmd/eval)       │
│    • 规范语义剪枝 (先行提取 JSON-LD)                   │ │    • 目录级 flock 排他锁 (防多实例脑裂)              │
│    • O(n) 树形 DP 计数器 (零中间字符串分配)            │ │    • truncateTornLine 物理截断 (自愈半截 JSON)       │
│    • 乘性四因子打分 (字符/标点/链接/长度)              │ │    • 双镜像持久化 (manifest 已抓 + queue 待抓)       │
│    • 祖先两层衰减累积 (资格与算分分离，own>0 门禁)     │ │    • fsync 强落盘 + 内存/磁盘条目强制对账            │
│    • Bigram 锚定打分 + 跨页模板剥离 (ChromeLearner)    │ │    • 多配置控制变量消融实验台                        │
└────────────────────────────────────────────────────────┘ └─────────────────────────────────────────────────────┘
```

## 二、 快速开始

### 1. 编译构建

```bash
# 环境要求 Go 1.26+
go build -o bin/crawler ./cmd/crawler
go build -o bin/extractor ./cmd/extractor
go build -o bin/seeds ./cmd/seeds
go build -o bin/eval ./cmd/eval

```

### 2. 流式抽取器（题目接口）

```bash
# 标准输入 JSONL -> 标准输出 JSONL ({url, meta_title, real_title, main_content})
./bin/extractor < input.jsonl > output.jsonl

# 汇总指标打印到 stderr
./bin/extractor -stats < input.jsonl > /dev/null

```

### 3. 礼貌并发爬虫

```bash
# 启动大规模跨域爬取（自动开启断点续爬与请求留痕）
./bin/crawler \
  -data /tmp/crawl_data \
  -seeds seeds/seeds.txt \
  -workers 32 \
  -delay 1500ms \
  -budget 30 \
  -per-host 15 \
  -trace /tmp/crawl_data/requests.trace

# 验证同域礼貌性（断言违规次数严格为 0）
python3 -c '
prev, viol = {}, 0
for line in open("/tmp/crawl_data/requests.trace"):
    ts, host, _ = line.rstrip("\n").split("\t")
    if host in prev: viol += (float(ts) - float(prev[host])) < 1.5 - 1e-5
    prev[host] = ts
print(f"Violations: {viol}")
assert viol == 0
'
```



## 三、 核心机制设计

### 1. 抽取算法：基于统计物理特征，不读 Class/ID

* **乘性四因子门控**：

$$
\text{Score} = \ln(1 + \text{Density}) \times (0.2 + 0.8 \times \text{PunctGate}) \times (1 - \text{LinkRate}) \times \text{LengthGate}
$$

采用乘性而非加权求和，只要链接密度高或无标点，乘积一票否决（100 字 `<p>` 得分 $\approx 2.9$，50 链接导航 div 得分 $\approx 0.14$，差距 20 倍）。

* **资格与累积拆开（Eligibility Decoupling）**：
  分数沿祖先向上汇聚 2 层，但**仅允许直属文本 $own > 0$ 的块参选最佳容器**。彻底解决小说站用 `<br>` 换行排版时 `<body>` 靠吃下全页碎片反超正文并触发判空规则的问题（空正文率 66.4% $\rightarrow$ 12.9%，已有正文样本 0 回归）。
* **真实标题 Bigram 锚定**：
  收集 OpenGraph、TwitterCard、JSON-LD、`<h1>`、`<title>` 分段构建候选池。以与正文前 200 字的字符级 2-gram 重叠率（权重 1.0）为核心。站名和栏目名绝不会出现在正文句首，真实标题天然胜出。

### 2. 爬虫引擎：双正交约束解耦

* **调度与限速分离**：单协程驱动最小堆（按 `nextAt` 排序），就绪域名投递给 `ready chan`（容量 32），Worker 消费慢时自动背压阻塞调度器，堆操作完全无锁。
* **物理出口时间闸（Gate）**：网络请求唯一出口 `doGet` 强行经过 `Gate` 校验。彻底消除 Worker 内“前置拉取 `robots.txt` + 正文请求”产生的 0 延迟突发流量。
* **三条算力止损线（Abandon）**：遇到①抓够配额、②连续失败超限、③站点 `Crawl-delay > 60s` 时，清空该域在 memory 中的排队队列，在途任务执行完毕自然排空，优雅弃域。

### 3. 断点续爬：崩溃自愈状态机

* **双镜像持久化**：同时记录已抓完的 `manifest.jsonl` 与待抓取的 `queue.jsonl`，防止重启后待抓 URL 丢失导致空转假死。
* **启动恢复四步时序**：

1. 抢占目录文件排他锁（`flock`），防双实例脑裂；
2. 执行 `truncateTornLine` 扫描文件尾部，物理截断残缺的半截 JSON，回滚脏数据；
3. 读取 Manifest 在内存恢复 `seen` 去重表；
4. 读取 Queue 重建 Host 队列与就绪最小堆，以 `O_APPEND` 恢复写入。

| ------------------------- | ------------------------------------------------------------ | ------------------------------------------------------- |

| **抓取规模 (进阶硬指标)** | **12,183 页**（覆盖 **1,028 个域**，其中 5,572 页判为正文页） | **100% 达成题目“1000 域 + 5000 HTML”硬性指标**          |
| **网络下载量**            | **1041.8 MB** (约 1GB 纯文本)                                | 编码自动适配（GB18030/Big5）无一次崩溃                  |
